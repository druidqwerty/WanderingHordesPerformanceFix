title=Wandering Hordes Save Trim [B42] - no more save freezes
description=[h1]Wandering Hordes without a bloated save[/h1]
description=An add-on for [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3759920384]Wandering Hordes[/url]. Wandering Hordes remembers walls, fences and water for every tile any player has ever been near (a "passability grid" in global ModData) and never forgets any. The game writes all global ModData into global_mod_data.bin at every world save, on the server's main thread, and reads it all at every start.

description=[h2]What goes wrong without it[/h2]
description=On our two-player co-op save:
description=[list]
description=[*]The wall map was [b]58 MB of a 76 MB[/b] global_mod_data.bin, and it grows with every trip (a long drive leaves a 61-tile-wide trail).
description=[*]Every world save (every 5 minutes) froze the server for ~0.3 s; the [b]first save after a start took 6.3 s[/b] and paused every player.
description=[*]Loading it took [b]6.9 s[/b] of every server start, and over 400 MB of the server's memory.
description=[/list]
description=
description=[h2]What the add-on does[/h2]
description=[list]
description=[*]Every 2 minutes it walks over the map, a few hundred cells per tick, and forgets the parts farther than 400 tiles from every player, from where each player joined the game (usually the base, also while you are away on a trip), from where offline players were last seen, and from every safehouse.
description=[*]Near the players nothing changes: 400 tiles covers everything Wandering Hordes' fence check can reach from a horde that appears near a player (75 + 300 tiles).
description=[*]Far away Wandering Hordes simply scans the area again when somebody comes back, as in a place nobody has visited yet.
description=[*]Works in single player and multiplayer. Wandering Hordes itself is not changed and none of its code is copied.
description=[/list]
description=

description=[h2]Requirements and installation[/h2]
description=[list]
description=[*]Build 42.21+ and [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3759920384]Wandering Hordes[/url] [Core]. No Java, no ZombieBuddy.
description=[*]Multiplayer: on the server add [b]WanderingHordesSaveTrim[/b] to Mods= (after WanderingHordesCore) and [b]3829140377[/b] to WorkshopItems=. Players who join get it from the Workshop.
description=[*]Can be added to an existing save: the first check trims the old map, the file shrinks at the next world save. Removing it later is safe.
description=[/list]
description=
description=[h2]Settings[/h2]
description=Host > Manage settings > Edit > Sandbox > [b]Wandering Hordes: Save Trim[/b], the same for everyone; an admin can change them in a running game (Admin > Sandbox options): [b]Trim Wandering Hordes' wall map[/b] (on), [b]Keep radius[/b] (400 tiles), [b]Keep around where players joined[/b] (on), [b]Keep around offline players[/b] (on), [b]Keep around safehouses[/b] (on), [b]Trim every[/b] (2 minutes), [b]Debug log[/b] (off).

description=[h2]Is it working?[/h2]
description=The server console has [noparse][WHSaveTrim] 1.0.0 loaded (server)[/noparse], and after the first check of an old save a line [noparse][WHSaveTrim] pass 1: ... removed (~48.4 MB) ...[/noparse].
description=
description=[h2]Known limitations[/h2]
description=[list]
description=[*]A trimmed place is like a new one for Wandering Hordes: it scans 30 tiles around the player at once and the rest as you walk around; until then a horde may appear inside a large fenced area it does not know yet. Your base is kept; make other important fenced places a safehouse or raise the radius.
description=[*]Only Wandering Hordes' table is touched; other mods' data in global_mod_data.bin stays.
description=[/list]
