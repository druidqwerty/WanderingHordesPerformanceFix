description=[h1]Wandering Hordes without the lag[/h1]
description=An add-on for [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3759920384]Wandering Hordes[/url]: removes what it costs in performance where it does nothing useful, and keeps what it does exactly the same. Formerly [b]Wandering Hordes Save Trim[/b] (same item, new name and mod id).
description=
description=[url=https://boosty.to/lrgpp][img]https://raw.githubusercontent.com/druidqwerty/WanderingHordesPerformanceFix/main/docs/banner.png[/img][/url]
description=Free and open source. The code is written by an AI; the direction, the testing and the time are mine. If the mod made your game better: [url=https://boosty.to/lrgpp]support on Boosty[/url].
description=
description=[h2]1. Clients run Wandering Hordes' server code for nothing[/h2]
description=Build 42 loads a mod's server files on every client too. Hordes are spawned, steered and saved by the server only, and zombies reach a client without any Wandering Hordes data, so on every player's machine this work is thrown away: its wall scanners every frame (0.2-0.4 ms), its migration map at game start (a [b]0.6 s freeze when you join[/b]) and again once per game day (~6 ms in every 5th frame for ~8 s), its horde managers and a Lua call on every zombie update. The add-on lets only the server run it; hordes behave the same.
description=
description=[h2]2. Its wall map bloats the save[/h2]
description=Wandering Hordes remembers walls and fences for every tile any player has ever been near and never forgets any. On our co-op save that was [b]58 MB of a 76 MB[/b] global_mod_data.bin, which the server writes at every world save and reads at every start. The add-on keeps that map only within 400 tiles of the players, of where each player joined (usually the base, also during a long trip), of offline players and of safehouses. That covers everything Wandering Hordes' fence check can reach near a player; far away it simply scans the area again when somebody comes back.
description=

description=[h2]Requirements and installation[/h2]
description=[list]
description=[*]Build 42.21+ and [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3759920384]Wandering Hordes[/url] [Core]. No Java, no ZombieBuddy.
description=[*]Multiplayer: on the server add [b]WanderingHordesPerformanceFix[/b] to Mods= (after WanderingHordesCore) and [b]3829140377[/b] to WorkshopItems=. Players who join get it from the Workshop.
description=[*]Had Wandering Hordes Save Trim? Replace WanderingHordesSaveTrim with WanderingHordesPerformanceFix in Mods=; the settings start from the defaults again, the remembered spots are taken over.
description=[*]Can be added to an existing save and removed later.
description=[/list]
description=
description=[h2]Settings[/h2]
description=Host > Manage settings > Edit > Sandbox > [b]Wandering Hordes: Performance Fix[/b], the same for everyone; an admin can change them in a running game: [b]Clients skip Wandering Hordes' server work[/b] (on), [b]Trim Wandering Hordes' wall map[/b] (on), [b]Keep radius[/b] (400 tiles), [b]Keep around where players joined[/b], [b]offline players[/b], [b]safehouses[/b] (on), [b]Trim every[/b] (2 minutes), [b]Debug log[/b] (off).
